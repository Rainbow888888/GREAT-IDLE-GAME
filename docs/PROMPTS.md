# Готовые промпты

Копировать как есть, подставив `<ID>`. Файл задачи — `docs/tasks/<ID>.md`.

## §1. Старт сессии кодера (OpenCode, после `/new`)

```
Проект SLIMEWARD2.0, папка O:\AI\SLIMEWARD2.0. Прочитай AGENTS.md, затем
docs/tasks/<ID>.md — это твоя задача, она главная. Дальше читай только то,
что требует порядок чтения в AGENTS.md для этой задачи.
Сначала одним абзацем скажи, как понял результат и критерии приёмки, и есть ли
противоречия со спекой. Если есть — остановись. Если нет — делай.
После реализации: прогон EditMode в batch, проверка тестов выпотрошенным методом,
затем вызови @reviewer по шаблону из docs/PROMPTS.md §2 и сохрани его ответ
в docs/reviews/<ID>/deepseek.md. Не коммить.
```

## §2. Вызов ревьювера DeepSeek (внутри сессии OpenCode)

```
@reviewer Задача: docs/tasks/<ID>.md (текст ниже).
Дифф: <вставить вывод git diff целиком>
Результат прогона тестов: <вставить итог batch-прогона: passed/failed, число, имена упавших>
Проверка выпотрошенным методом: <что выпотрошил, какие тесты покраснели>
```

Ревьювер не видит файлы сам — всё, что ему нужно, должно быть в запросе.

## §3. Ревью ChatGPT (отдельный чат, папка проекта подключена)

```
Ты второй независимый ревьювер проекта SLIMEWARD2.0 (папка O:\AI\SLIMEWARD2.0).
Прочитай AGENTS.md, docs/REVIEW_PROTOCOL.md, docs/tasks/<ID>.md и
docs/reviews/<ID>/deepseek.md. Проверь изменённые файлы задачи по диску
(git diff или сами файлы). Не повторяй находки DeepSeek — отметь только,
согласен ли ты с ними. Ищи то, что он пропустил.
Ответ строго в формате docs/REVIEW_PROTOCOL.md. Сохрани его в
docs/reviews/<ID>/chatgpt.md. Файлы проекта не правь.
```

## §4. Финальное ревью Claude (Cowork, папка подключена)

```

прочитай задачу, оба ревью в docs/reviews/<ID>/, проверь код по файлам.
Вердикт ACCEPT / FIX / STOP в docs/reviews/<ID>/claude.md, запушь.
```

## §5. Старт нового чата архитектора (Claude)


## §6. Закрытие чата архитектора

```
Закрываем чат. Обнови NEXT_CHAT.md по скиллу slimeward-handoff, запушь,
дай название следующего чата и стартовый промпт.
```
