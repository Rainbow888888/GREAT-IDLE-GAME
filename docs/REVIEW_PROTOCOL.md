# Протокол ревью

Канонический процесс находится в `docs/WORKFLOW.md`. Этот файл оставлен как короткая
точка входа для старых ссылок.

- Главное ревью делает Codex по фактическому diff и результатам тестов.
- Вердикт хранится в `docs/reviews/<ID>/codex.md`: `ACCEPT`, `FIX` или `STOP`.
- Claude пишет независимую критику в `docs/reviews/<ID>/claude.md` только на гейте
  этапа или по просьбе владельца.
- DeepSeek `@reviewer` необязателен.

Блокирующая находка обязана назвать файл/строку и сценарий: конкретный вход или
состояние → неверный результат. Стиль и личные предпочтения задачу не блокируют.
Визуал принимает только владелец по свежей сборке или в Play mode.
