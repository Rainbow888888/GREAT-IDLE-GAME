# Грабли Unity — перенесены из Stratosphere2

Каждая стоила там отдельного круга. Не повторять без новых данных.

1. **Ввод.** Шаблон включает новый Input System (`activeInputHandler: 1`), а UI
   использует легаси `StandaloneInputModule` → `InvalidOperationException` каждый кадр,
   клики не работают. Решение в Stratosphere: `activeInputHandler: 0` (Input Manager Old).
   Выбрать одно и проверить, что в `Player.log` нет исключений.
2. **Шрифт TMP.** В сборку не попадал текст. Включать штатный `LiberationSans SDF`
   (TMP Essential Resources), не системный шрифт. Кириллица: нужен шрифт с кириллицей
   и собранный атлас — проверить до первой русской строки в UI.
3. **URP-шейдер вырезается из сборки.** Материал, созданный кодом через `Shader.Find`,
   в билде становится нулевым. Решение: сериализованный материал в `Resources/`,
   грузится оттуда.
4. **Конструктор, который не досчитал состояние.** Объект после создания сообщал неверное
   состояние, пока не произойдёт первое событие. Любое вычисляемое состояние считать
   в конце конструктора; в тестах — предпроверка исходного состояния до действия.
5. **Литерал, дублирующий вычисление.** `x != null ? x.Count() : 2` — недостижимая ветка,
   которая вернула бы верный ответ при сломанной реализации и обманула бы проверку
   «выпотроши — тест покраснеет». Такие заглушки — дефект.
6. **Приёмка по старой сборке.** Конфиг из `Resources/` запекается в `.exe` в момент
   сборки. Старый `.exe` показывает старые числа и выглядит правдоподобно.
   Смотреть только свежую сборку или Play mode; постановка называет способ приёмки.
7. **Batch.** Тесты: без `-quit` при `-runTests`. Редактор должен быть закрыт.
   Сборка: `-batchmode -quit -executeMethod <Editor.BuildScript.Method>`.
8. **Версия.** Проект открывать строго в `6000.3.24f1` (`O:\UNITY\6000.3.24f1\Editor\Unity.exe`).
   Открытие в другой версии молча апгрейдит проект.
9. **`Library/`, `Temp/`, `Logs/`, `UserSettings/`, `Builds/`** — не в Git.

## Специфика 2D (проверить по выбранному стилю)

- Для pixel art: Pixel Perfect Camera + Point-фильтрация + отключённая компрессия.
- Aseprite Importer ставить только если арт действительно ведётся в Aseprite.
- Для high-res 2D не включать Pixel Perfect по инерции: проверить масштабирование,
  фильтрацию и компрессию на целевом разрешении.
- Много однотипных рабочих — пул объектов, а не Instantiate/Destroy на каждый.
- Большие числа: `double` в экономике; формат вывода (1.2K, 3.4M) — одна функция в Core.
