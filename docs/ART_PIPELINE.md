# Арт и анимация

Статус: варианты, решение — этап 6 (Q-002). До этапа 6 — только серые заглушки.

## Что вообще нужно такой игре

Incremental уровня Slimeward держится не на сложной анимации, а на «сочности» отклика:

- **Спрайтовые анимации по кадрам**: рабочий идёт / режет / несёт, здание работает,
  враг, босс. Порядка 4–8 кадров на цикл.
- **Процедурная анимация кодом** (не требует художника): подпрыгивание при покупке,
  squash & stretch, всплывающие числа, тряска камеры, мигание, твины UI.
- **Частицы**: искры резки, куски лома, дым, EMP-волна.
- **Эволюция зданий**: L1 / L3 / L6 — три картинки на здание, а не шесть.

Отсюда объём: ~10 зданий × 3 состояния, 6–7 типов юнитов × 2–3 анимации,
5 стадий корабля, UI-набор, иконки ресурсов. Это посильно.

## Источники арта

| Вариант | Плюсы | Минусы |
|---|---|---|
| Ассет-паки (itch.io, Unity Asset Store) | быстро, дёшево, сразу анимировано | чужой узнаваемый стиль, разнобой паков, проверять лицензию на коммерцию |
| ИИ-генерация + ручная доводка в Aseprite | свой стиль, дёшево | анимация по кадрам у генераторов нестабильна; нужна чистка руками; проверять права |
| Художник-фрилансер | цельный стиль, анимации «как надо» | деньги и сроки, нужно ТЗ |
| Смесь | статика — генерация/пак, анимации — художник или пак | нужно следить за единым стилем |

Рекомендация на обсуждение: смесь. Зафиксировать палитру и размер пикселя на этапе 6,
статику (здания, корабль, фон) — генерация + доводка, юнитов и эффекты — пак или художник.

## Технический конвейер (Unity)

- Aseprite → `.aseprite` прямо в `Assets/Game/Art/` → 2D Aseprite Importer делает
  спрайты и клипы по тегам.
- Pixel Perfect Camera, фиксированный PPU для всего арта.
- Git LFS включить до первого коммита арта:
  `git lfs install` и `git lfs track "*.png" "*.aseprite" "*.wav" "*.ogg"`.
- Код никогда не ссылается на арт по пути строкой — только через один реестр,
  чтобы серые заглушки менялись на арт без правки логики.
