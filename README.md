# GREAT-IDLE-GAME

Короткая incremental-игра с престижами и настоящим финалом.
Ориентир — Slimeward. Рабочее название — **The Wreck**: колония разбирает упавший корабль.

Unity `6000.3.24f1` · 2D · C#.

Сейчас делаем только первый 30–35-минутный забег. Решение о полной игре из пяти
забегов принимается после живого плейтеста вертикального среза.
