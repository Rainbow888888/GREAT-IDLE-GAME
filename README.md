# SLIMEWARD2.0

Короткая incremental-игра с престижами и настоящим финалом (4–5 часов).
Ориентир — Slimeward. Рабочий сеттинг — The Wreck: колония разбирает упавший корабль.

Unity `6000.3.24f1` · 2D · C# · код пишет ИИ, владелец — архитектор проекта.
