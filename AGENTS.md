# GREAT-IDLE-GAME — правила работы

Короткая 2D incremental-игра с конечным финалом. Рабочее название игры —
**The Wreck**; имя репозитория не является названием релиза.

Unity строго `6000.3.24f1`, C#. Владелец — Кларус. Общение и документы — на русском.

## Перед работой

1. Прочитать файл текущей задачи из `docs/tasks/`.
2. Прочитать `NEXT_CHAT.md` и проверить фактический `git status`/`git diff`.
3. Читать только относящиеся к задаче разделы `ROADMAP.md`, `PROJECT_CONTRACT.md`
   и `docs/BALANCE.md`.
4. Перед Unity/UI/сборкой прочитать `docs/UNITY_PITFALLS.md`.

Если задача противоречит контракту, текущему этапу или доступным данным — остановиться
до реализации и описать конфликт. Отчёт другого агента не заменяет проверку файлов.

## Границы реализации

- Одна задача даёт одно наблюдаемое изменение.
- Не трогать файлы и системы вне задачи; не рефакторить «заодно».
- Не строить абстракции для будущих забегов.
- Балансовые числа живут в JSON, не в C#.
- Экономика — чистый C# без `UnityEngine`; Unity-слой только показывает состояние
  и передаёт команды.
- Визуальное принимает владелец по свежей сборке или в Play mode.
- Идеи вне этапа записываются в `docs/DECISION_LOG.md`, но не реализуются.

## Роли

- **DeepSeek Pro/OpenCode** — основной исполнитель кода и тестов.
- **Codex** — архитектор и главный ревьювер: ставит задачи, проверяет фактический diff,
  тесты и соответствие контракту, при явной просьбе владельца правит проект.
- **Claude** — независимый критик. По умолчанию только читает и пишет свой отзыв;
  привлекается на гейтах этапов или по просьбе владельца.
- **DeepSeek `@reviewer`** — необязательная быстрая проверка внутри OpenCode.

Главный вердикт по задаче — `ACCEPT`, `FIX` или `STOP` от Codex. Мнение Claude не
считается автоматически правильным: решает конкретный сценарий отказа и решение владельца.

## Проверка

- Тесты проверяют точные ожидаемые значения и негативные случаи.
- Для критичной логики сделать mutation-check: временно сломать проверяемый метод,
  убедиться, что нужный тест краснеет, затем вернуть код.
- Unity EditMode запускается при закрытом редакторе:

```powershell
O:\UNITY\6000.3.24f1\Editor\Unity.exe -batchmode -nographics -projectPath O:\AI\GREAT-IDLE-GAME -runTests -testPlatform EditMode -testResults Logs\results.xml -logFile Logs\tests.log
```

Не добавлять `-quit` к `-runTests`.

## Git

- Источник правды — `O:\AI\GREAT-IDLE-GAME`; удалённая копия —
  `Rainbow888888/GREAT-IDLE-GAME`, ветка `main`.
- Перед правкой проверить статус. Чужие незакоммиченные изменения не перезаписывать.
- Добавлять поимённо только файлы задачи; `git add -A` не использовать.
- `git reset --hard`, force-push и удаление чужой работы запрещены.
- После собственного `ACCEPT` Codex сразу коммитит и пушит принятую задачу
  (постоянное разрешение владельца от 2026-09-20). В остальных случаях Git меняется
  только по явной команде владельца.
- После записи перечитать изменённые файлы с диска. «Готово» подтверждается diff,
  тестом или свежей сборкой, а не ответом инструмента.
