# GREAT-IDLE-GAME — передача контекста

Перед записью проверь путь, ветку, HEAD, `git status`, удалённый `main`, выполненные
тесты и текущий этап. Не переносить неподтверждённые заявления.

`NEXT_CHAT.md` должен содержать только:

1. проверенное состояние Git;
2. текущий этап и что фактически готово;
3. следующий один результат с критериями;
4. блокеры и открытые решения;
5. короткий порядок чтения;
6. один стартовый промпт.

Решения хранятся в `docs/DECISION_LOG.md`, а не дублируются целиком. После записи
перечитай файл с диска. Коммит и push — только по явной команде владельца.
