# GREAT-IDLE-GAME — вход в проект

1. Прочитай `AGENTS.md`.
2. Прочитай текущую задачу и `NEXT_CHAT.md`.
3. Проверь фактический Git-статус.
4. Работай только в границах назначенной роли и текущего этапа.

Этот skill намеренно не дублирует workflow. При расхождении всегда действует
`AGENTS.md`, затем файл текущей задачи.
